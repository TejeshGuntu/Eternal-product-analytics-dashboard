## 📌 Dashboard Overview

The Eternal_Combined.pbix report provides a centralized analytics view across key platforms within the Eternal ecosystem.

📑 Report Pages

1. 🏠 Dashboard – Main View
Centralized overview of key KPIs and performance metrics across all platforms.

2. 🍽️ Zomato View
Analyzes food delivery patterns, restaurant performance, ratings, customer preferences, and ordering behavior.

3. ⚡ Blinkit View
Provides insights into grocery sales, product categories, outlet performance, and consumer purchasing behavior.

4. 🎟️ District View
Analyzes booking trends across movies, events, and dining categories, highlighting customer preferences and category performance.

🔄 Navigation

Interactive navigation buttons enable users to seamlessly switch between report pages, creating a smooth and intuitive multi-page dashboard experience.
